# Isolated audit changes

Virus installation requires a GM-defined plan, spends the assigned actions and stores the successful roll as removal DV. Control compares against the incumbent result. Clone/import preserve floor graph and contents. Cancelled Interface rolls do not spend actions. The verifier now also resolves templates in a standalone checkout.

Tested against the installed Cyberpunk RED v0.92.4 / Foundry 12.331 installation in a separate data directory. This is an audit branch, not a published release. Some existing packs require Foundry 12.343; complete translation and all module combinations are not certified.
