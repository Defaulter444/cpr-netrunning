## Частицы и полноразмерные эффекты

Три PNG-текстуры (`circle_02`, `spark_01`, `light_02`) из [Kenney Particle Pack](https://kenney.nl/assets/particle-pack), автор Kenney, лицензия CC0 1.0. Исходные PNG с прозрачностью сохранены без изменений. Копия лицензии: `assets/console/fx/LICENSE.txt`.

Анимации сканирования, сборки программы, разряда и взлома написаны для этого модуля на Canvas 2D. Текстуры включены в модуль и работают без интернета. Переключатель «Анимации» выключает эффекты. Системное уменьшение движения учитывается по умолчанию; пользователь может выбрать «Полные эффекты в этой консоли». Эти семь эффектов остаются без звука.


## Профили ЛЬДА (1.11.0)

Двенадцать цифровых силуэтов и их анимации созданы для модуля на Canvas 2D (`ice-art.mjs`); звуковые сигналы синтезируются локально через Web Audio. Новые сторонние изображения или аудиозаписи не распространяются. Портреты сущностей берутся из установленной системы Cyberpunk RED или из настроенной карточки пользователя. Тестовые изображения из D:\Pictures и материалы из тестового мира в сборку не включены.
