# Проверка версии 1.8.0

## Автоматические проверки

- Все 13 файлов `tools/test-*.mjs` завершились успешно.
- `node --test tools/scanner/*.test.mjs`: 96 тестов, 0 ошибок.
- `node tools/verify.mjs`: 0 ошибок, 24 предупреждения о классах CSS (включая динамические классы шаблонов).
- Сохранены дополнительные проверки пользовательского чёрного льда и демонов из релиза 1.7.8.

## Живая проверка

Проведена в отдельном тестовом мире на Foundry VTT 12.331, Cyberpunk RED Core 0.92.4, с мастером и двумя игроками.

- При выключенном сканере обычные архитектуры открываются; шаблоны точек и панели сканера не создаются.
- При включении создаются шесть шаблонов. Панель, редактор и подписи отображаются на русском.
- Штатные броски Сканера мастером и игроком сохраняют карточку системы и открывают панель мастера с результатом. Обычный Бэкдор не запускает сканер.
- Приватное открытие точки видно выбранному игроку; публичное — обоим. Проверены сигнал, скрытие и переход к связанной архитектуре.
- У игрока название скрыто за закрытой дверью, появляется после открытия и снова скрывается после закрытия, даже если туман уже исследован.
- При выбранном мастером персонаже необнаруженные точки не подписаны ни за стеной, ни в поле зрения. После обнаружения показывается только видимая этому персонажу точка. Снятие выделения возвращает общий вид мастера.
- Перехвачена утечка через стандартную подпись токена Foundry.

Совместное владение несколькими персонажами, дополнительные типы точек и отдельные пограничные случаи проверены автоматическими тестами; полного ручного прогона всех сочетаний других модулей не проводилось. Во время последней живой проверки наблюдалась отдельная ошибка загрузки звука Dice So Nice; ошибок сканера не было.

## Установка

Сканер выключен по умолчанию. Для включения нужен активный `lib-wrapper` и перезагрузка мира. Подробности: [SCANNER.md](SCANNER.md).
