# Находки и характер ЛЬДА

## Файлы на этаже

1. Мастер открывает редактор архитектуры и нажимает **«Находки · настроить»** на нужном этаже.
2. В набор можно добавить до 12 записей: досье, переписку, изображение, аудиозапись или план объекта. Для переписки есть поля отправителя и получателя. Изображение, план и звук выбираются через файловый менеджер Foundry.
3. Нажмите **«В черновик архитектуры»**, затем сохраните саму архитектуру. Отмена редактора оставляет исходные файлы без изменений.
4. Игрок проходит **«Идентификацию»** по обычным правилам. После успеха карточка на площадке открывает все вложения. До проверки содержимое и миниатюры не показываются.
5. В открытой находке кнопка **«Сохранить в коллекцию»** создаёт постоянную копию. Повторное сохранение той же записи тем же игроком не создаёт дубликат.

Раздел **«Находки»** в верхнем меню работает и после отключения. Поиск охватывает название и текст. В сохранённой карточке **«Показать группе»** позволяет выбрать получателей. Они получают доступ и личную ссылку в чате. Аудио запускается только кнопкой проигрывателя.

Изменение или удаление исходного файла не меняет уже сохранённую копию. Для сохранения и передачи нужен подключённый Мастер. Существующие текстовые файлы и изображения переносятся в журналы автоматически при входе основного Мастера; они остаются доступны через привычные карточки и экспорт архитектуры.

### Хранение

Содержимое хранится на страницах журналов Foundry с закрытым доступом по умолчанию. Архитектура содержит ссылку на исходный журнал. Сохранённая находка — отдельный журнал с правами наблюдателя у получателя. Исходные журналы удалённых этажей сохраняются для восстановления. При экспорте архитектуры Мастером вложения входят в JSON; медиафайлы необходимо переносить отдельно.

Файловое хранилище Foundry раздаёт медиа по URL. Для скрытых иллюстраций и записей используйте непредсказуемые имена и ограничьте игрокам просмотр файлового хранилища. Доступ к журналу не шифрует сам медиафайл.

## Собственный характер ЛЬДА

Все 12 стандартных типов имеют цвет, цифровой силуэт, спокойное движение и реакции на появление, атаку, преследование и уничтожение. Пользовательский ЛЁД сохраняет загруженный портрет и получает общий цифровой эффект.

| ЛЁД | Характер атаки |
|---|---|
| Аспид | Извивающийся бросок |
| Гигант | Тяжёлый кулак и разлетающиеся блоки |
| Адская гончая | Рывок с огненным следом |
| Кракен | Щупальца от источника к цели |
| Лич | Кольцо рун вокруг цели |
| Ворон | Полёт по дуге с цифровыми перьями |
| Скорпион | Удар жалом по дуге |
| Скунс | Расширяющееся облако помех |
| Блуждающий огонёк | Электрический импульс |
| Дракон | Поток пламени |
| Убийца | Рывок и перекрёстные лезвия |
| Саблезуб | Прыжок и смыкающиеся клыки |

Атака начинается у атакующего токена и направлена в выбранную видимую цель. Преследователь проходит по доступным связям схемы. Уход из видимости не считается уничтожением. Открытие окна и переключение участника не повторяют прошлые события.

**«Вид и эффекты → Характер Чёрного ЛЬДА»** содержит выбор типа и события для предпросмотра. Он не бросает кубы и не расходует действия. Звук выключен по умолчанию; громкость настраивается отдельно и учитывает громкость интерфейса Foundry. Эффекты учитывают системное уменьшение движения, останавливаются при закрытии окна и скрытии вкладки.

Визуальное поведение дополняет действующие боевые правила. Статы, урон и правила преследования остаются в системе Cyberpunk RED.
